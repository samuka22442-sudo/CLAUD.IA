# NetDiagram

Editor simples de diagramas de rede no navegador (React + Vite + Tailwind CSS).

- Adicione equipamentos (roteador, switch, servidor, PC, internet, firewall, AP) clicando ou arrastando.
- Defina nome, quantidade de portas e cor de cada equipamento.
- Arraste de uma porta até outra para puxar um cabo (Ethernet, fibra, console, Wi-Fi), com cor, estilo e texto.
- Adicione textos livres, nomeie cada projeto, alterne entre projetos.
- Salvamento automático no navegador; exporta/importa JSON e exporta PNG.

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # build de produção em dist/
```
